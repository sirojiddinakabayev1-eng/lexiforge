# LexiForge — Custom Alphabet, Linguistics & Cipher Studio

**Live Platform:** https://lexiforeguz.netlify.app

LexiForge is a full-stack computational linguistics and cryptography web application that enables users to invent custom 28-letter alphabets, transform entire user interfaces dynamically, and exchange encrypted messages.

### Key Features & Engineering:
- **28-Letter Custom Script Engine:** Users assign 100 unique, non-letter geometric symbols to each character, dynamically transforming the entire website UI and virtual keyboard into their invented script.
- **Bi-Directional Cipher Messenger:** Messages are encoded using base character indices (0–27), allowing senders and recipients to toggle any message between the sender's alphabet, the recipient's alphabet, or standard text (UZ/RU/EN) in real time.
- **Linguistics & Dictionary Studio:** Create custom vocabulary, export/import shareable alphabet keys, and explore public languages created by other users.
- **Security & Moderation:** Includes 4-digit PIN app lock, 10-minute self-destructing messages, a one-click Panic Button, and an Admin moderation dashboard with automatic translation for safety compliance.
- **Zero-Lag Architecture:** Built with pure HTML, CSS, JavaScript, and Supabase without heavy external AI dependencies for instant performance on mobile devices.
